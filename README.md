# Plate Picker

A fun Gradio app that generates random license plate numbers with customizable colors and styles!

## Features

- Generate random license plate numbers
- Choose from different plate colors (Blue, Green, Red, Black)
- Select different plate styles (Standard, Premium, Classic, Modern)
- Interactive web interface powered by Gradio

## Usage

Simply select your preferred color and style, then click "Generate Plate" to create a random license plate!
